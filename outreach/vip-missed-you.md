## 3. If you want to run it live instead

You can reschedule it once, but do it inside the campus and put it on a
specific day with a reason attached, not "we will try again."

Something like: **Thursday 8 PM, Set Breakdown Night. Post your set in the
thread before then so I have them ready.**

The thread does the work either way. If four people post before Thursday,
you have a live session with something to open. If nobody posts, you break
them down in the thread and you have lost nothing.

I would run the thread first. An empty room twice costs more than an empty
room once.

---

## What I would not do

Do not tell anybody the room was empty. Not in the post, not in the story,
not in a DM. Sixteen people reading "nobody showed up" hear "her rooms are
empty," and that is a harder thing to walk back than one quiet night.

"I missed y'all" carries everything you actually want to say.
